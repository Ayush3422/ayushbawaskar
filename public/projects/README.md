# Project Images Folder

Place your project screenshots, diagrams, and GIFs here.

## Expected Files

### AI Image Classifier
- `classifier-architecture.png` - Model architecture diagram
- `classifier-training.png` - Training curves/metrics
- `classifier-results.gif` - Demo of classification in action
- `classifier-confusion-matrix.png` - Confusion matrix visualization

### Smart Chatbot
- `chatbot-interface.gif` - UI demo
- `chatbot-analytics.png` - Analytics dashboard
- `chatbot-architecture.png` - System architecture

### Blockchain DApp
- `dapp-interface.gif` - DApp UI demo
- `dapp-transaction.png` - Transaction flow
- `dapp-architecture.png` - Smart contract architecture

### Data Visualization Dashboard
- `dashboard-overview.gif` - Dashboard demo
- `dashboard-charts.png` - Chart examples
- `dashboard-filters.png` - Filter/interaction features

## Tips
- Keep file sizes under 2MB (5MB max for GIFs)
- Use descriptive names matching the `screenshots` array in `projects.js`
- PNG for static images, GIF for animations
- Recommended width: 1200-1600px
